# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Delegated by the user's request to build: static HTML, CSS and JavaScript, portable hosting through Sites. No server is required for a presentation and illustrative interaction.

## Users
Developers evaluating a self-hosted coding-agent engine. English and Polish are explicitly requested.

## Product Purpose
Build a distinctive, exciting presentation for szpont-engine, explain its thread-based workflow, and lead interested developers to the repository and setup documentation.

## Positioning
A private Discord thread retains a CLI runner session on the owner's Linux machine. Durable SQLite work queue and private Markdown context provide continuity.

## Capabilities and Constraints
Current source v0.11.1. Codex default; Claude Code and OpenCode experimental. One owner and one global worker. Codex supports supervised goals with explicit repository diff evidence. Offline demonstrations use synthetic responses. Do not claim guaranteed recovery or external delivery, live-model proof, or parallel workers. No invented user counts or testimonials. Model access is separate from the MIT license.

## Brand Commitments
Source brand guide: lowercase hyphenated szpont-engine; supplied unmodified continuous-thread logo; orange #FF6B35, graphite #111315, paper #F3F0E8. Clear sans-serif type and specific English, with a full Polish translation requested by the user.

## Evidence on Hand
https://github.com/dalkedev/szpont-engine ; README.md, docs/brand.md, docs/runners.md and v0.11.1 release verified 2026-11-11. Existing logo and social artwork downloaded from source assets.

## Open Decisions
Domain not purchased. szpont.dev is recommended; szpont-engine.com also available at the time checked. Website deployment begins as owner-private preview.

## Product Principles
- Make the actual Discord-to-runner mechanism tangible.
- Give precise setup guidance.
- Show illustrative activity honestly.
- Preserve the existing project identity.
