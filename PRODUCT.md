## Platform
web

## Stack
Delegated by the user's request to build: static HTML, CSS and JavaScript, portable hosting through Sites. No server is required for a presentation and illustrative interaction.

## Users
Developers evaluating a self-hosted coding-agent engine. English and Polish are explicitly requested.

## Product Purpose
Build a distinctive, exciting presentation for plompy-engine, explain its thread-based workflow, and lead interested developers to the repository and setup documentation.

## Positioning
A private Discord thread retains a CLI runner session on the owner's Linux machine. Durable SQLite work queue and private Markdown context provide continuity.

## Capabilities and Constraints
Current source v0.12.0. Codex default; Claude Code and OpenCode experimental. One owner and one global worker. Codex supports supervised goals with explicit repository diff evidence. Offline demonstrations use synthetic responses. Do not claim guaranteed recovery or external delivery, live-model proof, or parallel workers. No invented user counts or testimonials. Model access is separate from the MIT license.

## Brand Commitments
The user selected lowercase hyphenated plompy-engine, with Plompy as the short mascot name. A playful, slightly absurd fish gives the project its character. Preserve the approved orange #FF6B35, graphite #111315 and paper #F3F0E8 palette, navbar and footer. Clear sans-serif type and specific English, with a full Polish translation requested by the user.
