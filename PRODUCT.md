# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Static HTML, CSS and JavaScript served from Vercel. The site presents the engine and Local MCP gateway through illustrative interactions and setup guides.

## Users
Developers evaluating a self-hosted coding-agent engine. English and Polish are explicitly requested.

## Product Purpose
Explain Plompy's thread-based Discord workflow and local MCP gateway. Give visitors a direct path to the setup instructions for their chosen mode.

## Positioning
A private Discord thread retains a CLI runner session on the owner's Linux machine. Durable SQLite work queue and private Markdown context provide continuity.

## Capabilities and Constraints
Stable v0.13.1 includes the Discord engine and a Local MCP kit with a configurable loopback port. The Discord engine supports one owner and one global worker. Codex is the default Discord runner and supports supervised goals with explicit repository diff evidence. The Discord adapters for Claude Code and OpenCode remain experimental. The Local MCP gateway can connect independently to compatible clients. Notes, tasks and one-time reminders are available in the 1.0.0-alpha.1 personal assistant preview. Offline demonstrations use synthetic responses. Model access is separate from the MIT license.

## Brand Commitments
The user selected lowercase hyphenated plompy-engine, with Plompy as the short mascot name. A playful, slightly absurd fish gives the project its character. Preserve the approved orange #FF6B35, graphite #111315 and paper #F3F0E8 palette, navbar and footer. Clear sans-serif type and specific English, with a full Polish translation requested by the user.

## Evidence on Hand
The engine README, runner guide and versioned releases describe product behavior. The generated website docs come from the engine's `docs/local/` sources and publication catalog.

## Open Decisions
The name plompy-engine is selected. The user purchased plompy.dev; the public EN/PL website is live on Vercel at https://plompy.dev. DNS remains at OVH, HTTPS is active, and www redirects to the apex domain. Google Search Console ownership is verified and its sitemap successfully processed both language pages on 2026-11-12. The owner-private Sites preview is served at https://plompy-engine.violet-quail-2164.chatgpt.site.

## Product Principles
- Make the actual Discord-to-runner mechanism tangible.
- Give precise setup guidance.
- Show illustrative activity honestly.
- Use one Plompy identity across the site, source repository and social artwork.
